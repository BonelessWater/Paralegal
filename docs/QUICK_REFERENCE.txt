┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔧 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem: vLLM container won't start
  ├─ Check GPU: ls -la /dev/kfd /dev/dri
  ├─ Check logs: docker logs vllm-rocm
  └─ Verify ROCm: /opt/rocm/bin/rocminfo

  Problem: Model download fails (Llama 3)
  ├─ Accept license: https://huggingface.co/meta-llama
  ├─ Check token: echo $HUGGING_FACE_HUB_TOKEN
  └─ Try manual: huggingface-cli login

  Problem: API returns 500 errors
  ├─ Check model loaded: docker logs vllm-rocm | grep "Loading"
  ├─ Wait 60 seconds after start
  └─ Restart: docker restart vllm-rocm

  Problem: Out of memory
  ├─ Use smaller model (Llama 3 8B instead of 70B)
  ├─ Reduce batch size in start_vllm.sh
  └─ Check: docker stats vllm-rocm

  Problem: Slow inference
  ├─ Check GPU usage: rocm-smi
  ├─ Verify ROCm optimization: docker logs vllm-rocm | grep "ROCm"
  └─ Reduce max_model_len in start_vllm.sh
